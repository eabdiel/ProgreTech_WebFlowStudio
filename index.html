Hybrid Security Boundary

Outbound only

Interactive recording and browser execution belong on an approved Local Client inside the user's existing network context. BTP hosts orchestration, metadata, preview, governance, scheduling, distribution, audit and results. WebFlow does not provide VPN, proxy, port-forwarding, arbitrary URL tunneling, or firewall-bypass capabilities.
